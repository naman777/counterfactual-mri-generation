# Saved demo evidence

Generated by `python -m api.build_demo`. The manifest lists the 20 selected slices and exact requests.
Each JSON contains images, foreground histogram, CPU judge probabilities, metrics and B3 provenance.
Both axis presets and same-noise null edits are saved (80 results). No new diffusion sampling.
Selection is illustrative and includes disagreement. Cohort estimates come from Results.
Copy this directory with the app for replay. No GPU or model loading is used for these requests.
